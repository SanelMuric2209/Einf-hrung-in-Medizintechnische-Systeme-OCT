# Optical Coherence Tomography (OCT) Scan Analysis

This repository contains the source code and documentation for our project on Optical Coherence Tomography (OCT) scans, developed for the course **Einführung in Medizintechnische Systeme**.

## 📖 About the Project
Optical Coherence Tomography (OCT) is a non-invasive imaging technique that uses low-coherence light to capture micrometer-resolution, two- and three-dimensional images from within optical scattering media (e.g., biological tissue). 

This project focuses on the computational analysis and processing of OCT scan data. Our goal is to apply digital signal and image processing techniques to enhance scan readability, reduce noise, and highlight critical anatomical structures.

### Key Features
* **Data Import:** Parsing and loading raw OCT scan data formats.
* **Image Pre-processing:** Speckle noise reduction and contrast enhancement.
* **Segmentation (Optional):** Identifying and isolating specific tissue layers.
* **Visualization:** 2D/3D rendering of the processed medical images.

## ⚙️ Prerequisites
To run this project locally, you will need the following installed on your machine:
* **MATLAB** (Version R2021a or newer recommended)
* **MATLAB Image Processing Toolbox**
* **MATLAB Signal Processing Toolbox** (If applying advanced filtering)
